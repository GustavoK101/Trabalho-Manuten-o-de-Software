Ponto de Partida

O que era o projeto?

O projeto original é o exemplo oficial do Socket.IO — um chat minimalista usado como material de tutorial.

  • 📄2 arquivos: index.js (servidor) e index.html (cliente)
  • 🗄️SQLite para persistência de mensagens
  • ⚙️Node.js cluster para escalar em múltiplos núcleos
  • 🔄Connection state recovery para reconectar sem perder histórico
Análise Inicial

Problemas encontrados

🐛 Verificação frágil de erro

Comparava e.errno === 19 em vez de usar e.code === 'SQLITE_CONSTRAINT', que é estável.

🔇 Erros silenciados

Blocos catch vazios: falhas no banco e na recuperação de mensagens eram descartadas sem log.

🚪 Porta sem fallback

process.env.PORT undefined causava listen(undefined) — porta aleatória sem aviso.

⚠️ Sem validação de entrada

Qualquer payload (não-string, vazio, gigante) chegava ao banco sem verificação.

Correções

Bugs corrigidos

// Antes
if (e.errno === 19) { callback(); }

// Depois
if (e.code === 'SQLITE_CONSTRAINT') { callback(); }
else { console.error('DB insert error:', e); }

// Validação adicionada
if (typeof msg !== 'string' || msg.trim().length === 0 || msg.length > 500) {
  return callback({ error: 'invalid message' });
}
Refatoração

Estrutura modular

O index.js acumulava responsabilidades demais. Separamos em módulos coesos:

  • 🗃️db.js — abre conexão SQLite e cria tabelas
  • 💬chat.js — registra todos os handlers de Socket.IO (mensagens, digitação)
  • 🔌index.js — camada de montagem: cluster, servidor HTTP, Express e Socket.IO

Cada módulo tem uma única responsabilidade, facilitando testes e manutenção.

Novas Funcionalidades

O que foi adicionado?

👤 Nomes de usuário

Usuário escolhe um nome ao entrar. Persistido no banco e exibido em cada mensagem.

⌨️ Indicador de digitação

Mostra "João está digitando..." para os outros usuários em tempo real.

🕐 Timestamp

Horário de envio armazenado no banco (UTC) e exibido ao lado de cada mensagem.

🔔 Mensagens do sistema

Avisa quando alguém entra ou sai do chat: "Maria entrou no chat".

👥 Contagem de usuários

Barra superior mostra quantos usuários estão conectados no momento.

✉️ Mensagens privadas

Clique em um usuário na lista lateral para abrir uma conversa 1-a-1.

Tecnologia

Stack utilizada

⚡ Socket.IO 4

Comunicação bidirecional em tempo real com reconnect automático e state recovery.

🟢 Node.js + Express

Servidor HTTP leve, cluster nativo para escalar em múltiplos CPUs.

🗄️ SQLite

Banco embarcado, sem dependências externas. Ideal para escala pequena e demonstrações.

🧪 Vitest

Runner de testes moderno com suporte nativo a ESM. Rápido e compatível com Vite.
